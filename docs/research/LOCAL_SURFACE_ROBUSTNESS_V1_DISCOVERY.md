# LOCAL_SURFACE_ROBUSTNESS_V1 — discovery only

This layer prevents repeated 15-minute observations from masquerading as independent evidence. It persists contract/session episodes, daily stratum summaries, ordered cross-date transfer diagnostics, and residual-tail sensitivity to spread and timing quality.

Readiness is governed by distinct session dates: <2 insufficient for cross-date; 2–4 cross-date descriptive only; 5–19 exploratory stability only; 20+ ready only for preregistration review. None enables p-values, BH/FDR, candidate creation, admission, trading, or an edge claim.
